Rishit's Stereo — generated static player

Files (put all four in the same folder):
  index.html
  style.css
  script.js
  songs.js

No assets folder required — album art uses built-in note icons
(green in dark theme, blue in light theme).

Open index.html in a browser, or push the folder to GitHub Pages.

Tracks stream from:
https://github.com/Rishit-1010/Stereo/releases/tag/Stereo1

Features:
  - Desktop layout + automatic phone/tablet layout
  - Dark / light theme toggle
  - Sleep timer (1/2/3/5 hours + custom)
  - Add song (local mp3, saved in this browser)
  - Liked songs, search, categories, now playing
